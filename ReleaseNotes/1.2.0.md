WattBar 1.2.0 · macOS 13+ · Apple silicon and Intel

- More accurate readings: distinguish missing sensors from zero and preserve real zero power values.
- Battery power is no longer substituted for total system power while plugged in.
- Correctly distinguish charging from plugged in but not charging.
- Hide battery controls on desktop Macs with a placeholder battery registry entry.
- Bound sensor work to one read at a time, cache SMC metadata, pause polling during sleep, and reconnect after wake.
- Use a lightweight AppKit entry point and release Preferences when closed.
- Keep preferences in sync with menu changes and report Launch at Login errors and required approval.
- Control automatic update checks in Preferences. Signed feeds and archives preserve the key trusted by WattBar 1.1.0.
- Universal download and a new website with automatic GitHub Pages deployments.

Sensor decoding and release metadata have automated tests. The app was checked on an Apple silicon desktop Mac. Physical battery/charger transitions, sleep/wake, login-item approval, and Intel hardware still need testing on those setups. Sensor support varies by model; a dash means no reading is available.
